# Milol

وب‌سایت جدید، ساخته‌شده با React + Vite + Tailwind CSS.

## اجرا در محیط محلی

```bash
npm install
npm run dev
```

## ساخت نسخه نهایی

```bash
npm run build
npm run preview
```

## انتشار

با هر push روی برنچ `main`، سایت به‌صورت خودکار روی GitHub Pages منتشر می‌شود.
یک بار در تنظیمات ریپو، بخش **Pages**، گزینه Source را روی **GitHub Actions** بگذارید.
